# rice monitor

[English](README.md) · [简体中文](README.zh-CN.md) · **Русский**

Приватный форк [Pane для Windows](https://github.com/ItsJazii/pane) на базе коммита `a55578c`, доступный в виде исходного кода. Приложение на Tauri, Rust и TypeScript показывает лимиты ИИ-аккаунтов и отдельно разрешённую статистику локальных журналов.

> Приложение называется **rice monitor**, собственная нумерация начинается с **0.0.1**. Предыдущий код прошёл тесты Windows CI и сборку NSIS; это не подтверждает проверку новой версии, установки, трея или реальных аккаунтов. См. текущие проверки PR и [инструкцию обновления](docs/rice-monitor-0.0.1.md).

## Изменения форка

- Телеметрия и автоматическое обновление upstream удалены. Обновление требует проверки и повторной сборки исходного кода.
- Доступ аккаунтов изначально выключен. Единый раздел **Управление платформами / Platform management** содержит разрешения аккаунтов, режимы подключения, ключи и отображение метрик. Включение платформы не разрешает запросы отдельных аккаунтов; выключение отзывает все её разрешения на запросы и обновление токенов. Скрытие метрики меняет только отображение.
- У каждого инструмента есть отдельный выключенный по умолчанию переключатель журналов и выбор **Default location** или **Custom locations**. Отсутствующий каталог не означает выключение; ошибка сохранения пользовательского пути оставляет прежнее разрешение без автоматического перехода к стандартным путям. Локальная статистика не требует разрешений аккаунтов. Новые подписи доступны на китайском и английском, с английским резервным вариантом для русского.
- One/New API и Sub2API удалены. Остальные 22 семейства сохранены, включая локальные Hermes и Ollama; с экспериментальным CommandCode всего 23.
- Настройки Windows хранятся в `%APPDATA%\PanePrivate`. Настройки, ключи и кеши Pane/OpenUsage автоматически не импортируются.
- В исходном коде реализованы точные региональные режимы, ручная синхронизация цен, хеши фрагментов журналов и координация OAuth. См. [границы проверки](docs/private-build.md#integration-status): синтетические тесты и проверки для целевой платформы не подтверждают нативное поведение Windows.

Стоимость по журналам является оценкой, а не счётом или доказательством принадлежности расходов аккаунту. Токены моделей без известной цены учитываются; неизвестная цена не считается нулевой.
