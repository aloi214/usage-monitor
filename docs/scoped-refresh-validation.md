额外回归探针检查了：

- 新的钱包失败使用实际尝试时间；冷却重放和单独刷新套餐不伪造新钱包时间。
- 钱包尚无成功数值时，首次失败及来源信息仍能保留；未知成功时间保持未知。
- 目标账户请求进行中，另一个账户失效且访问策略版本未变化时，旧结果不会恢复该账户。
- 当前空发布结果优先于旧磁盘缓存；钱包来源不可信时移除其行及历史信息。

## 验证边界

- 未读取真实账户凭据或用户日志，未调用真实服务商接口。
- 合成 DOM 测试不等于浏览器视觉验收或 Windows/WebView2 实机操作；系统托盘、原生拖拽与键盘交互仍需实测。
- GNU 目标类型检查不等于 Windows MSVC 编译、链接、安装或启动成功。
- 未验证最终安装体积、启动速度或 LTO 构建内存占用；发布优化不清理开发缓存。
- 保留既有 OAuth 保护与已记录的运行边界；此次没有声称修复所有服务商限流或登录过期问题。

操作方式见[单账号额度刷新](scoped-quota-refresh.md)。原手动 Claude 版本的 486 项 Rust / 124 项 Node 结果仅作为历史记录，不用于代表本次验证。
