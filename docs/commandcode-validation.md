## 独立复查

- 确认原有 22 个平台在访问、托盘及前端注册中保留，CommandCode 仅新增一次。
- 合成接口检查真实适配器的授权、固定主机及路径、重定向拒绝、密钥替换、限流与响应解析；没有真实账户请求。
- 额外探针覆盖非法数值、服务端上限优先、带敏感内容的失败响应、恶意 URL、无关缓存隔离和精确目标的身份读取范围。
- 前端另行通过 11 项完整模块 DOM 探针：密钥、授权、移除及重置操作交错，失败后的恢复，旧响应抑制，以及原有平台和来源控制保留。
- 密钥只由用户在本机填写。本次未创建、配置或验证真实密钥。CommandCode 密钥更改前先清理已保存的旧额度，失败不把旧查询结果当作新密钥的数据。
- 缺失字段不补零；月度只显示剩余 credits，不从套餐宣传值推算用量。部分订阅信息不可用时保留有效额度并展示警告。

## 测试边界

五个 Rust 测试包使用实际模块或从源文件提取的原始函数体，配合合成配置、临时文件及测试网络边界。新增网络测试执行实际 CommandCode 适配器；用量测试执行实际查询、权限、缓存及密钥变更路径。Node 测试启动实际前端模块，使用模拟 Tauri IPC、时钟及合成数据。

正常 DOM 测试工具对 SVG 原始导入存在既有模拟限制；独立检查临时修正该测试导入后验证了新增图标 DOM，不代表视觉验收。
